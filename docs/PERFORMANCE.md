## プロフィール画像

トップのLCP要素はプロフィール画像でした。390px幅・DPR2では240pxの表示枠に対して828pxの画像を取得していました。必要な480pxの候補は既にあり、画像本体は39,744バイトから20,314バイトへ約49%小さくできます。

`Profile.astro`のCSSに合わせて`PROFILE_AVATAR_SIZES`を指定し、4つの画面幅・DPR2で必要な表示密度を満たしながら480px以下の候補を取得することを確認しています。上の表は変更前の計測値です。

本番コミット`680bc34`を反映した後、トップだけを同じ条件で3回計測しました。

| 項目 | 変更前 | 変更後 |
| --- | ---: | ---: |
| 選択された画像幅 | 828px | 480px |
| 画像本体 | 39,744バイト | 20,314バイト |
| ページ転送量中央値 | 187.6KB | 168.1KB |
| LCP中央値 | 2.468秒 | 2.288秒 |
| CLS最大 | 0 | 0 |

変更後の3回とも480pxの候補を取得し、ブラウザエラーやリソース取得失敗はありませんでした。画像本体は約49%減っています。LCPにはネットワークや実行環境の揺れも含まれるため、この3回の差だけで恒常的な短縮幅とは判断しません。

記事と検索については、この計測だけから追加変更が必要とは判断していません。
